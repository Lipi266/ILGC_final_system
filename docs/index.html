System Requirements

Windows

  • Windows 10 or later
  • 4GB RAM minimum
  • Webcam
  • 500MB disk space

macOS

  • macOS 10.15 or later
  • 4GB RAM minimum
  • Webcam
  • 500MB disk space

Optional

  • Bluetooth (for HR monitor)
  • Heart rate band (hBand)
  • Stable internet connection
